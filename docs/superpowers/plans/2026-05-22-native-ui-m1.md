# Native UI M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first real native LightLaunchpad surface that opens instantly without cold-starting WPF.

**Architecture:** Add `LightLaunchpad.NativeUi`, a C++ Win32 process that owns the hotkey, tray, window, search text, drawing, and launching. It reads the existing `%AppData%\LightLaunchpad\settings.json` and `layout.json`, enumerates the existing launchpad folder, and renders a read-only launchpad grid with native drawing. WPF remains in the repo as fallback/settings/editing while native UI grows.

**Tech Stack:** C++17, Win32 API, GDI double-buffered drawing for M1, shell APIs for icons and launching, MinGW build scripts, existing C# source tests as structural guardrails.
